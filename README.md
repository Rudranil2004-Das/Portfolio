# Rudranil Das - Portfolio (React + Python)

## Backend (Terminal 1)
cd backend
python -m venv venv
venv\Scripts\activate          (Mac/Linux: source venv/bin/activate)
python -m pip install -r requirements.txt
python app.py

## Frontend (Terminal 2)
cd frontend
npm install
npm run dev

Open http://localhost:5173
Put your photo at frontend/public/profile.jpg
Edit your details in frontend/src/data.js
